Movie API

Über das Projekt

RESTful-API, die Daten zu Filmen, Regisseuren und Genres aus einer MongoDB-Datenbank abruft, indem sie HTTP-Anfragen an den Server sendet.

Ziel

Die API, die Daten aus einer MongoDB-Datenbank abruft, sollte später auf der Client-Seite in React verwendet werden.

Kontext

Die API war Teil des Webentwicklungskurses bei CareerFoundry, um Fähigkeiten in der serverseitigen Programmierung aufzubauen.

Projektbeschreibung CareerFoundry (source: CareerFoundry)

Tech Stack

  • Node.js
  • NPM
  • MongoDB
  • Mongoose
  • Express.js
  • Heroku

Key Features

  • Eine Liste aller Filme an den Benutzer zurückgeben
  • Daten zu einem einzelnen Film anhand des Titels an den Benutzer zurückgeben
  • Daten zu einem Genre (Beschreibung) anhand des Namens/Titels (z. B. „Thriller“) zurückgeben
  • Daten zu einem Regisseur (Biografie, Geburtsjahr, Sterbejahr) anhand des Namens zurückgeben
  • Neuen Benutzern die Registrierung ermöglichen
  • Benutzern die Aktualisierung ihrer Benutzerdaten ermöglichen
  • Benutzern ermöglichen, einen Film zu ihrer Favoritenliste hinzuzufügen
  • Benutzern ermöglichen, einen Film aus ihrer Favoritenliste zu entfernen
  • Bestehenden Benutzern die Abmeldung ermöglichen
